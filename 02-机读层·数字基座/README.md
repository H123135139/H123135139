## 调用顺序

口袋问当下 → 卡片做检修 → 齐家管耦合。

说明：本目录只有三件——口诀、修身卡、齐家卡。
"检修层""耦合层"是各自卡片的**动作**，不是独立的第四件文件：
做检修＝用修身卡，管耦合＝用齐家卡。

前置纪律：先修身后齐家，单脊柱不立者勿直接调用齐家卡；
修身卡与齐家卡互相不得缩放替代（详见各卡 warning）。
