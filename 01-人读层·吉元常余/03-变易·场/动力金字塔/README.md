# 人类动力金字塔 ×《山海经》：解码躺平时代的文明密码

**版本**：v1.0.1（新增卷首引与红线）

> 拍板权在人，锚在当下，律在体感。——《吉元节律》

---

人不是突然不想动的。
是被一层一层冻住了。

从婴儿落地时的第一次抓握，到临终前的最后一次呼吸，
所有"主动动起来"的力量，都源于同一套底层逻辑。

我们把它画成一座五层金字塔：

┌─────────────────┐
│ ⑤ 愿景之光 │ ← 为谁而活？意义何在？
├─────────────────┤
│ ④ 爱与连接 │ ← 被看见、被需要、有归属
├─────────────────┤
│ ③ 七情六欲 │ ← 喜怒哀乐，情绪自然流动
├─────────────────┤
│ ② 应激反应 │ ← 怕死、怕穷、怕失去——生存本能
├─────────────────┤
│ ① 感官敏感期 │ ← 赤脚踩地、闻花香、听雨声——身体在说话
└─────────────────┘

**下层卡住，上层一定转不动。**
一个睡不好觉的人，谈不了人生使命；
一个长期孤独的人，再大的愿景也显得空洞。

这不是懒，是系统冻结。

而《山海经》，早在四千年前就记录了人类集体的"冻结"与"解冻"：

- **精卫填海**：不是执念，是第三层冻结后，用行动代替哭泣；
- **共工怒触不周山**：不是暴怒，是第二层失控引发的文明崩塌；
- **昆仑虚**：不是仙境，是第五层在黑暗中为人类点亮的灯塔；
- **雷泽有神，龙身人面**：不是怪物，是第一层全然打开时，对世界的敬畏。

《山海经》不是神话，
是人类文明的**动力诊断手册**。

今天你感到"躺平"，
不过是又一次站在了冰山边缘。

不必责怪自己。
只需问：
**哪一层冻住了？**

- 身体麻木，连饭都不想吃？→ 回第一层：赤脚踩草地10分钟
- 总担心钱不够、未来无望？→ 回第二层：先吃一顿热饭，确认安全
- 哭不出来也笑不出来？→ 回第三层：把话写下来，或对一棵树说
- 觉得没人需要你？→ 回第四层：养一盆要每天浇水的绿萝
- 不知道活着为了什么？→ 回第五层：问自己："我最想看见什么画面成真？"
