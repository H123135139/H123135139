# 玩棋问妙 v1.1.0

**发布日期**：2026年9月4日
**性质**：非商业开放共享 · 自我平衡练习

---

## 是什么

一个自己跟自己玩的平衡小游戏。

生活里每一件让你卡住、紧绷、放不下的事，都是一枚棋子。
你不需要看懂整盘人生，只练习三件事：**看见棋子，调整自己，轻轻走一步**。

---

## 材料

不需要棋盘，不需要道具。
只用你已有的三样东西：

- 一件当下真实发生的事
- 你自己的身体感受
- 一次愿意停下来的机会

---

## 四步

**第一步：挑一枚棋子**
从心里装着的事情里，挑出最让你紧绷的那一件。
不用急着分析它，先承认：这就是我此刻手上的棋子。

**第二步：摸一摸自己的状态**
把注意力从棋子收回，放到自己身上。
问问自己：我现在是快要撑不住？还是平平淡淡没力气？还是刚好准备迈出一步？

根据感觉，选一种玩法：
- **稳住**：暂时离开这枚棋子，脚踩地，叹口气，先不下
- **滋养**：不着急走，给自己一段安静的时间，慢慢攒力气
- **校准**：回看来路，想最小的一步是什么，感受肩膀是松还是紧

身体感觉说了算。

**第三步：轻轻走一步**
调整完之后，如果还想走，就走一步。
只走一步。很小的一步。负担得起的一步。
不需要完美解法，走了就够了。

**第四步：看一看新局面**
走完那一步，停下来。
看看棋子现在落在哪了，自己的感受有没有变化。
这一轮结束，等下一枚棋子出现。

---

## 自由玩法

没有规则。
你可以用任何你舒服的方式玩这个棋子。可以改名，可以加减步骤，可以跟别人一起玩，可以画出来，可以写下来。

唯一的底线：**这个游戏是用来帮你自己更清楚、更轻松的，不是用来评判自己、逼自己的。**

如果玩着玩着变成了新的压力，那就放下。过一阵子再拿起来玩。
